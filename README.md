## Overview
Expo AI is a powerful AI-based Telegram chatbot designed to provide fast, intelligent, and flexible responses to user queries. It supports real-time typing, advanced analysis, and seamless integration with modern APIs.

The system is built to deliver an unrestricted conversational experience with high performance and scalability.

## Architecture
Frontend and backend handled using Next.js  
Telegram Bot API manages messaging  
Groq API powers AI responses  
System designed for real-time interaction and scalability  

---

## Project Structure
/components  Reusable modules  
/pages       Next.js routes  
/api         Bot and AI endpoints  
/utils       Helper functions  
/lib         API configurations
